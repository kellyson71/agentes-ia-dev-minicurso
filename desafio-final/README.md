# Desafio final

Agora é a vez do aluno repetir o exercício sozinho, sobre o mesmo
`demo-site/`.

## Tarefa proposta

Adicionar um **filtro nos cards de programação** (por período: manhã /
tarde), ou, alternativamente, **validação no botão de inscrição** (exigir
nome e e-mail antes de confirmar).

Assim como no exercício de dark mode, essa tarefa tem uma decisão de
projeto em aberto:

- Onde deve morar a lógica do filtro/validação (JS inline, arquivo
  separado, atributos `data-*`)?
- O que deve acontecer com os cards que não passam no filtro (escondidos?
  removidos do DOM?)
- O botão de inscrição deve dar feedback visual imediato, ou só ao
  submeter?

## Como praticar

1. Escreva primeiro um prompt mínimo (o mais curto e natural possível) e
   rode contra o `demo-site/`.
2. Anote as decisões que o agente tomou sozinho.
3. Reescreva o prompt com restrições explícitas (mesma lógica dos
   Experimentos 1 e 2 em `prompt-experiments/`).
4. Compare os dois resultados.
5. Opcional: rode a skill `frontend-review` sobre o resultado final.
