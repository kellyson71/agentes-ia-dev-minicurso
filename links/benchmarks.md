# Benchmarks e comparação de modelos

Úteis para a parte da aula sobre "não existe um modelo melhor absoluto" —
o "melhor" depende do critério (preço, velocidade, contexto, tarefa).

- [Artificial Analysis — Leaderboard de modelos](https://artificialanalysis.ai/leaderboards/models) —
  compara inteligência, preço, velocidade, latência e contexto lado a lado.
- [OpenRouter — Rankings](https://openrouter.ai/rankings) — ranking por uso
  real na plataforma; bom para mostrar que uso não é sinônimo de qualidade.
- [OpenRouter — Coding Models](https://openrouter.ai/collections/programming) —
  o mesmo recorte, focado em modelos usados para programação.
- [SWE-bench](https://www.swebench.com/) — benchmark de agentes resolvendo
  problemas reais de software (issues de projetos open source).
- [Aider Leaderboard](https://aider.chat/docs/leaderboards/) — comparação
  de modelos especificamente em tarefas de edição de código.
