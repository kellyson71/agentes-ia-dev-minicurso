# Experimento 2 — Prompt estruturado

## Prompt usado

```
Adicione um modo escuro à página existente.

- Preserve o layout e os estilos atuais.
- Use as CSS variables existentes ao invés de sobrescrever cores nos
  componentes.
- O botão deve ficar no header.
- O tema deve persistir após recarregar a página, usando localStorage.
- Não adicione bibliotecas.
- Não altere o conteúdo da página.
```

## O que observar durante a execução ao vivo

- O agente respeitou as CSS variables (criando um segundo bloco, ex.
  `[data-theme="dark"] { --background: ...; --text: ... }`)?
- O botão ficou no header, como pedido?
- O tema persistiu ao recarregar a página?
- Nenhuma dependência nova foi adicionada?
- O conteúdo textual da página ficou intacto?
- Quantos arquivos ele tocou no total? Comparar com o Experimento 1.
